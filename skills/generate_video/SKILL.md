# Generate Video (nano-banana, Veo)

Create a video from a text prompt, animate a still image, or extend a
previously generated video, using Google's Veo models through the
`@the-focus-ai/nano-banana` CLI.

Use this when the user asks for a video, an animation, "make this image move",
or to extend a clip.

## Requirements

- `GEMINI_API_KEY` set (the CLI reads `.env` itself). Key from
  <https://aistudio.google.com/apikey>.
- `npx` on `PATH`, or `npm install -g @the-focus-ai/nano-banana`.
- `file` (the MIME-type utility) on `PATH`: the CLI shells out to
  `file --mime-type` for `--file` and `--reference` inputs. Without it those
  modes fail. This is not documented in the CLI's `--help`.

### Check that this key can make videos at all

Video is **not** available on every Gemini key, even when image generation works
fine on the same key. Verify before you spend anything:

```bash
npx @the-focus-ai/nano-banana --list-models
```

The output has an `Image Generation:` section and a `Video Generation (Veo):`
section. If the Veo section is empty, this key has no video entitlement and every
`--video` call will fail with:

```
404 NOT_FOUND  models/veo-3.1-... is not found for API version v1beta,
               or is not supported for predictLongRunning
```

That 404 is an **account/entitlement** problem (Veo needs an eligible plan, often
a paid tier of Google AI Studio / Vertex), not a bad flag and not a bad prompt.
Report it as such instead of retrying variations of the command. Querying the
model directly returns the same 404:

```bash
curl -s -o /dev/null -w '%{http_code}\n' \
  "https://generativelanguage.googleapis.com/v1beta/models/veo-3.1-generate-001" \
  -H "x-goog-api-key: $GEMINI_API_KEY"
```

Video generation is **slow and expensive**: the CLI prints a cost estimate,
starts an operation and polls every 10s with a **5-minute timeout**. A single
clip routinely takes 2–4 minutes. Always run it as a foreground `bash` command
and be prepared to wait; never assume it finished in a second.

## Command shape

Video mode is enabled by `--video` (or implicitly by `--extend` / `--estimate-cost`).
The prompt is positional, `--prompt "<text>"`, or `--prompt-file <path>`.

| Option | Meaning |
| --- | --- |
| `--video` | Enable video generation mode |
| `--file <image>` | Image to animate (image-to-video) |
| `--output <file>` | Output path. Default: `output/video-<timestamp>.mp4` (or `<image>-animated.mp4`) |
| `--video-fast` | Use `veo-3.1-fast-generate-001` — cheaper and faster |
| `--video-model <name>` | Explicit Veo model. Default `veo-3.1-generate-001` |
| `--duration <4\|6\|8>` | Seconds. Default `8`. Any other value is an error |
| `--resolution <720p\|1080p\|4K>` | Default `1080p`. 4K only on preview models |
| `--aspect <16:9\|9:16>` | Default `16:9`. `9:16` for vertical/social |
| `--audio` / `--no-audio` | Audio is on by default; `--no-audio` saves cost |
| `--reference <image>` | Style/character reference, max 3. Requires `--duration 8` |
| `--extend <video.mp4>` | Continue a previously generated video |
| `--seed <n>` | Seed for reproducibility |
| `--estimate-cost` | Print a cost estimate and exit without generating |

## Hard rules the CLI enforces

These exit 1 with a message; check them before you run, not after:

1. **`--resolution 1080p` requires `--duration 8`.** For a 4s or 6s clip you
   must pass `--resolution 720p`.
2. **`--reference` requires `--duration 8`.**
3. **`--extend` requires `--duration 8`**, forces `720p`, and cannot be combined
   with `--reference` or `--file`.
4. **At most 3 `--reference` images.**
5. **`--extend` only works on videos this CLI produced**: it reads a sidecar
   `<name>.uri` file written next to the `.mp4` at generation time. A video from
   anywhere else has no `.uri` and is rejected.
6. **`--prompt` and `--prompt-file` are mutually exclusive.**

## Prompt structure

Video prompts work best in this order:

```
[Camera movement] + [Subject] + [Action] + [Setting] + [Aesthetics] + [Audio]
```

- **Camera** — "slow dolly in", "static wide shot", "aerial orbit", "handheld follow".
- **Subject and action** — one clear action; Veo handles a single beat better
  than a scripted sequence.
- **Setting and light** — place and time of day.
- **Aesthetics** — film stock, palette, mood ("cinematic, warm tungsten, 35mm").
- **Audio** — describe what should be heard, since audio is generated by default.

Example:

```
--video "Slow dolly-in on a neon-lit ramen counter at night, steam rising from a
bowl, a chef's hands entering frame, shallow depth of field, cinematic teal and
orange palette, ambient street noise and gentle sizzling"
```

## Examples

```bash
# Cheap first draft: fast model, short, silent
npx @the-focus-ai/nano-banana --video "A robot dancing in a spotlight" \
  --video-fast --duration 4 --resolution 720p --no-audio --output videos/dance.mp4

# Animate a still image
npx @the-focus-ai/nano-banana --video "The character smiles and turns to camera" \
  --file images/portrait.png --output videos/smile.mp4

# 8-second 1080p hero clip (the only duration 1080p allows)
npx @the-focus-ai/nano-banana --video "Aerial orbit over a misty pine forest at dawn" \
  --resolution 1080p --duration 8 --output videos/forest.mp4

# Extend a clip you generated earlier
npx @the-focus-ai/nano-banana --video "The camera continues forward through the trees" \
  --extend videos/forest.mp4 --duration 8 --output videos/forest-part2.mp4

# Price it before paying for it
npx @the-focus-ai/nano-banana --video "A sunset over mountains" --duration 8 --estimate-cost
```

## Cost control

- **Estimate first.** For anything over one clip, run `--estimate-cost` and
  report the figure to the user before spending.
- **Draft with `--video-fast --duration 4 --resolution 720p --no-audio`.**
  Duration, resolution and audio are the main cost levers.
- The CLI itself documents the range as roughly **$0.10–$0.75 per second**
  depending on model. Quote the estimate it prints, not this range.

## Rules

- **Always pass `--output`** ending in `.mp4`, and verify the file exists and is
  non-empty afterwards (`ls -l`). A timeout leaves nothing behind.
- **Quote the whole prompt** as one argument.
- **Prefer the draft settings for iteration**, then re-render the winner.
- **Keep the `.uri` sidecar.** Do not move or delete it for a clip that might
  need extending later.
- **Do not retry immediately on timeout.** The 5-minute timeout in the CLI is a
  client-side poll limit; the operation may still be running. Re-run
  deliberately, or lower the cost settings.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| `1080p resolution only supports 8-second videos` | Duration/resolution conflict | Use `--resolution 720p` for 4/6s |
| `Reference images require 8-second videos` | `--reference` with short duration | Add `--duration 8` |
| `Video extension requires 8-second videos` | `--extend` with short duration | Add `--duration 8` |
| `Cannot use --file with --extend` | Both inputs given | `--extend` already implies the source video |
| `URI file not found ... need .uri file` | Extending a foreign video | Only extend clips this CLI made |
| `Video generation timeout after Ns` | Poll limit hit | Lower cost settings and retry |
| `404 NOT_FOUND ... not supported for predictLongRunning` | Key has no Veo entitlement | Check `--list-models`; upgrade the account, or use the image skill instead |
| `No video generated in response` | Refusal or upstream error | Read the printed error, adjust the prompt |
| `GEMINI_API_KEY environment variable is not set` | Key missing | Add it to the project env file, or export it |
